# Sign Brothers Odoo Scripts — Install / Update

Use this page to install or refresh the approved Sign Brothers Odoo userscripts.

## Before you begin

1. Install and enable the **Tampermonkey** browser extension.
2. In Chrome, open **Extensions → Tampermonkey → Manage Extension** and make sure **Allow User Scripts** is enabled.
3. Open each Install / Update link below. Tampermonkey will show a confirmation screen; choose **Install** or **Update**.

> Tampermonkey installs one userscript per confirmation, so complete all five links. You can share this repository page in company Google Chat as the single starting link.

## Install / Update all five scripts

1. [Odoo All Tasks Customizer — Install / Update](https://github.com/JPSignBros/OdooScripts-Install/raw/refs/heads/main/DesignBoard%20script.user.js)
   - All Tasks column widths, automatic group expansion, group colors, and cell highlighting.

2. [Odoo Persistent List Column Widths — Install / Update](https://github.com/JPSignBros/OdooScripts-Install/raw/refs/heads/main/OdooColumnWidth.user.js)
   - Saves manually resized column widths in Odoo list views.

3. [Odoo Universal Search — Install / Update](https://github.com/JPSignBros/OdooScripts-Install/raw/refs/heads/main/OdooUniversalSearch.user.js)
   - Adds the permanent cross-module search bar.

4. [Odoo Right-Click Cell Edit — Install / Update](https://github.com/JPSignBros/OdooScripts-Install/raw/refs/heads/main/RightClicktoEdit%20script.user.js)
   - Enables right-click editing of supported list-view cells.

5. [Odoo Custom Shortcut Dashboard — Install / Update](https://github.com/JPSignBros/OdooScripts-Install/raw/refs/heads/main/ShortCutBar%20script.user.js)
   - Adds persistent shortcuts to saved Odoo views.

## Updating later

Reopen this page and click the relevant Install / Update link. Tampermonkey identifies the existing script by its name and namespace and will offer the appropriate installation or update flow.

Future published versions use stable update and download URLs from this repository. The private development and planning repository remains separate.
